⚙️ How the auto-update works

A GitHub Action (.github/workflows/update-readme.yml) runs on every push and:

Scans the repo root for folders matching {number}-{slug}
Looks up each problem's real title & difficulty via LeetCode's public GraphQL API
Rewrites the table above and commits the change back — no manual edits needed

To trigger it manually, run the workflow from the Actions tab (Run workflow).
